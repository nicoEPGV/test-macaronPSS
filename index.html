Mode d’emploi

🟦 1) Créer le macaron
Activité / Programme : choisis dans la liste.
Pastilles : clique sur les cercles autorisés (cercles grisés = verrouillés).

🎨 2) Choisir une couleur
Sélectionne une couleur fédérale.

📐 3) Choisir une résolution (HD)
1024 px : web léger
2048 px (recommandé)
4096 px : très HD (plus long)

⬇️ 4) Télécharger
PNG : fond transparent
JPEG : fond blanc
ZIP activité : pack complet
ZIP macarons figés : officiel 🔒
